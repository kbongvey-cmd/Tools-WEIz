TOOLS WEI — Accounting & Inventory PRO
========================================
Offline-first wholesale inventory/accounting app. No API and no server.

HOW TO USE
1. Open index.html in Chrome, Edge, Firefox or Android Chrome.
2. Add products before recording sales or purchases.
3. Record purchases to increase stock; sales reduce stock.
4. Use Backup to download JSON regularly.
5. Restore imports a prior JSON backup and replaces current data.

GITHUB PAGES
1. Extract this ZIP.
2. Upload index.html and README.txt to the ROOT of your repository (not inside a nested folder).
3. Commit to main.
4. GitHub repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

IMPORTANT
- Data is stored in the browser on the device. It does not automatically sync between devices.
- Clearing browser data can erase records. Back up frequently.
- Financial reports are basic management estimates, not audited accounting statements.
- Version 1.0 supports single-item sales/purchase transactions; advanced tax, multi-line invoices, barcode scanning and multi-user sync are not included.
